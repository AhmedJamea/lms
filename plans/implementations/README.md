# Implementation Plans

This directory holds one detailed plan per started milestone. It is intentionally empty of active plans until work is authorized.

## Required workflow

1. Copy `IMPLEMENTATION_PLAN_TEMPLATE.md` to `<milestone-id>-implementation-plan.md`.
2. Fill every section with implementation-level decisions grounded in the corresponding `plans/milestones/M*.md` scope and the current repository.
3. Request and receive approval before implementation, unless the user explicitly waives approval.
4. Update the same plan as scope, assumptions, or delivery decisions materially change.

The mandatory gate is also defined in the repository-root `AGENTS.md`.
