# LMS V1 Milestones

This directory is the authoritative release roadmap for the LMS V1 conversion. Milestones are sequential unless a detailed implementation plan identifies a safe dependency-free workstream.

| Order | Milestone | Outcome |
|---|---|---|
| M0 | [Release foundation](M0-release-foundation.md) | A secure, deployable, maintainable platform base and a production UI foundation. |
| M1 | [School setup and access](M1-school-setup-and-access.md) | A school can configure its organization, academic structure, facilities, staff, and permissions. |
| M2 | [Timetables](M2-timetables.md) | Staff can create and publish conflict-free class, teacher, and resource schedules. |
| M3 | [Examinations and grading](M3-examinations-and-grading.md) | Staff can schedule examinations, manage seating/invigilation, and record validated results. |
| M4 | [Approval, reporting, and promotion](M4-approval-reporting-and-promotion.md) | Results become approved records that drive reporting, fees, progression, graduation, and archives. |
| M5 | [Release hardening](M5-release-hardening.md) | V1 is operationally ready, observable, recoverable, accessible, and release-approved. |

## Start rule

Before work begins on a milestone, follow [the implementation-plan gate](../implementations/README.md). The repository-level `AGENTS.md` enforces this rule for all implementation work.
